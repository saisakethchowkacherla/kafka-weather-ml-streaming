### Step 1: Start Services (2 min)
```bash
docker-compose up -d
```

### Step 2: Setup Python (1 min)
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### Step 3: Run Components (3 terminals, 2 min)
```bash
# Terminal 1:

python weather_producer.py
```
